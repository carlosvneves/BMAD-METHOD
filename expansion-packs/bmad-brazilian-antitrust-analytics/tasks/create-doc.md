## INSTRUÇÕES PARA CRIAÇÃO DE DOCUMENTOS ECONOMÉTRICOS

Este processo guiado ajudará você a criar um documento econométrico completo para análise de mercado brasileiro e detecção de cartéis.

### PASSO 1: TIPO DE DOCUMENTO
Selecione o tipo de documento econométrico que deseja criar:

1. **Relatório de Modelo Econométrico** - Documentação completa de modelo econométrico
2. **Relatório de Previsão Econômica** - Análise de previsão com intervalos de confiança
3. **Estudo de Inferência Causal** - Documentação de estratégia de identificação causal
4. **Avaliação de Política Econômica** - Análise de impacto de políticas
5. **Relatório de Detecção de Cartel** - Análise especializada para investigações CADE
6. **Relatório de Mercado Brasileiro** - Análise de estrutura e dinâmica de mercado
7. **Relatório de Análise de Licitações** - Detecção de padrões suspeitos em licitações públicas
8. **Relatório de Simulação de Fusão** - Análise de efeitos competitivos de fusões
9. **Relatório de Análise de Preços** - Análise de paralelismo de preços para investigações
10. **Relatório de Dano Econômico** - Cálculo de danos para casos antitruste

**Digite o número correspondente ao tipo de documento desejado:**

### PASSO 2: CONTEXTO DA ANÁLISE
Forneça informações sobre o contexto da sua análise:

- **Setor/Mercado:** Descreva o setor econômico ou mercado em análise
- **Objetivo Principal:** Qual é o objetivo principal desta análise econométrica?
- **Dados Disponíveis:** Descreva os dados que você tem disponíveis (fonte, período, variáveis)
- **Questões de Pesquisa:** Liste as principais questões de pesquisa que deseja responder
- **Stakeholders:** Quem são os principais interessados nos resultados desta análise?

### PASSO 3: ESCOPO E PROFUNDIDADE
Defina o escopo e profundidade da análise:

- **Abordagem Metodológica:**
  - [ ] Análise de Séries Temporais (ARIMA, VAR, GARCH)
  - [ ] Microeconometria (modelos de escolha discreta, painel)
  - [ ] Inferência Causal (IV, DiD, RD, Matching)
  - [ ] Análise de Cartel (screening, padrões de preços, licitações)
  - [ ] Machine Learning para Detecção de Colusão
  - [ ] Análise de Redes para Detecção de Cartel
  - [ ] Simulação de Fusões e Efeitos Competitivos
  - [ ] Análise de Poder de Mercado

- **Nível de Detalhe:**
  - [ ] Análise Exploratória (visão geral e estatísticas descritivas)
  - [ ] Análise Intermediária (modelos básicos e diagnósticos)
  - [ ] Análise Avançada (modelos complexos e testes de robustez)
  - [ ] Análise Completa (todos os níveis com validação completa)

- **Foco Geográfico:**
  - [ ] Mercado Nacional Brasileiro
  - [ ] Análise Regional (especifique regiões)
  - [ ] Análise Estadual (especifique estados)
  - [ ] Análise Municipal (especifique municípios)
  - [ ] Análise Internacional Comparada

### PASSO 4: PREFERÊNCIAS TÉCNICAS
Configure as preferências técnicas para a análise:

- **Linguagem de Programação Preferida:**
  - [ ] R (recomendado para econometria)
  - [ ] Python (para ML e integrações complexas)
  - [ ] Ambos (R para econometria, Python para ML)

- **Métodos de Séries Temporais:**
  - [ ] Teste de Estacionaridade: ADF, KPSS, PP, Zivot-Andrews
  - [ ] Modelagem Inicial: VAR para entender relações
  - [ ] Modelagem Avançada: ARDL se resultados não forem bons
  - [ ] Análise de Não Linearidade: Terasvirta, White, Keenan, McLeod-Li
  - [ ] Testes de Causalidade: Entropia de Transferência, Convergência Cross-Mapping

- **Validação de Modelos:**
  - [ ] Testes de Diagnóstico Completo
  - [ ] Análise de Sensibilidade
  - [ ] Testes de Robustez
  - [ ] Validação Cruzada

### PASSO 5: ENTREGÁVEIS ESPERADOS
Defina o que você espera receber:

- **Formato do Relatório:**
  - [ ] Relatório em Português Brasileiro (texto e análise)
  - [ ] Código Comentado em Inglês
  - [ ] Visualizações e Gráficos
  - [ ] Dados Processados
  - [ ] Resultados Quantitativos
  - [ ] Recomendações para CADE/SEAE

- **Nível de Automação:**
  - [ ] Análise Completa Automatizada
  - [ ] Análise Guiada com Validação Manual
  - [ ] Framework para Análise Replicável
  - [ ] Dashboard Interativo

### PASSO 6: CRONOGRAMA E PRIORIDADES
Defina prioridades e restrições de tempo:

- **Prazo para Entrega:** Quando você precisa dos resultados?
- **Prioridade de Análise:** O que é mais importante (precisão, velocidade, abrangência)?
- **Restrições Técnicas:** Alguma limitação de dados, software ou hardware?
- **Nível de Urgência:** Esta análise é para investigação ativa, planejamento, ou pesquisa?

## PROCESSAMENTO DA SOLICITAÇÃO

Com base nas suas respostas, eu vou criar um documento econométrico completo seguindo estes padrões:

### Metodologia Recomendada
- **Análise Exploratória:** Estatísticas descritivas, visualizações, testes preliminares
- **Modelagem Econométrica:** Modelos apropriados para o tipo de dados e questões de pesquisa
- **Validação:** Testes de diagnóstico, análise de sensibilidade, validação cruzada
- **Interpretação:** Resultados em português com contexto brasileiro, implicações para políticas
- **Recomendações:** Sugestões baseadas em evidências para investigações antitruste

### Qualidade e Padrões
- **Precisão Estatística:** Métodos econométricos apropriados e validação rigorosa
- **Relevância para CADE:** Foco em evidências para investigações antitruste brasileiras
- **Transparência:** Código bem documentado e metodologia reproduzível
- **Atualização:** Métodos atualizados conforme melhores práticas em econometria

### Linguagem e Comunicação
- **Relatórios em Português:** Análise e recomendações em português brasileiro
- **Código em Inglês:** Variáveis, funções e comentários em inglês
- **Contexto Brasileiro:** Consideração das particularidades do mercado brasileiro
