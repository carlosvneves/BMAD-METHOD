## ELICITAÇÃO AVANÇADA PARA PESQUISA ECONOMÉTRICA BRASILEIRA

Este processo guiado realiza elicitação avançada para projetos complexos de pesquisa econométrica no contexto brasileiro de antitruste.

### PASSO 1: TIPO DE ELICITAÇÃO
Selecione o tipo de elicitação necessária:

**Categoria de Elicitação:**
- [ ] **Elicitação de Problema:** Definição precisa do problema de pesquisa econométrica
- [ ] **Elicitação de Metodologia:** Seleção e validação de métodos econométricos
- [ ] **Elicitação de Dados:** Identificação e caracterização de fontes de dados
- [ ] **Elicitação de Hipóteses:** Formulação e refino de hipóteses testáveis
- [ ] **Elicitação de Política:** Tradução de resultados em recomendações de política
- [ ] **Elicitação de Validação:** Verificação da robustez e validade dos resultados
- [ ] **Elicitação de Aplicação:** Identificação de aplicações práticas para CADE

**Nível de Complexidade:**
- [ ] **Básico:** Questões diretas com respostas objetivas
- [ ] **Intermediário:** Problemas com múltiplos fatores e trade-offs
- [ ] **Avançado:** Questões complexas com incerteza e múltiplas perspectivas
- [ ] **Especializado:** Tópicos técnicos com conhecimento especializado requerido

### PASSO 2: CONTEXTO DO PROJETO
Forneça informações sobre o contexto do projeto:

**Descrição do Projeto:**
- **Título do Projeto:** Nome ou descrição curta do projeto
- **Área Temática:** Setor econômico ou área de investigação
- **Patrocinador:** Quem está patrocinando ou solicitando esta análise?
- **Prazo:** Qual é o prazo para conclusão da análise?
- **Orçamento:** Há restrições orçamentárias ou de recursos?

**Stakeholders Principais:**
- **Decisores:** Quem vai tomar decisões baseadas nos resultados?
- **Especialistas:** Quem são os especialistas de domínio disponíveis?
- **Usuários:** Quem vai utilizar os resultados da análise?
- **Revisores:** Quem vai revisar e validar a análise?

**Objetivos do Projeto:**
- **Objetivo Principal:** Qual é o objetivo principal desta elicitação?
- **Objetivos Secundários:** Quais são os objetivos secundários?
- **Deliverables Esperados:** O que você espera produzir com esta elicitação?
- **Critérios de Sucesso:** Como você vai medir o sucesso da elicitação?

### PASSO 3: DOMÍNIO CONCEITUAL
Explore o domínio conceitual da pesquisa:

**Conceitos Chave:**
- **Conceitos Econômicos:** Poder de mercado, eficiência, bem-estar
- **Conceitos Jurídicos:** Infração à ordem econômica, domínio de mercado
- **Conceitos Estatísticos:** Significância, confiança, viés
- **Conceitos de Mercado:** Relevante mercado, concorrência efetiva
- **Conceitos Setoriais:** Especificidades do setor em análise

**Relacionamentos entre Conceitos:**
- **Relações Causais:** Como os conceitos se relacionam causalmente?
- **Relações de Dependência:** Quais conceitos dependem de outros?
- **Relações de Hierarquia:** Como os conceitos se organizam hierarquicamente?
- **Relações Temporais:** Como os conceitos evoluem no tempo?

**Teorias Relevantes:**
- **Teoria Econômica:** Quais teorias econômicas são relevantes?
- **Teoria Organizacional:** Teorias sobre comportamento empresarial
- **Teoria de Jogos:** Estratégias e interações competitivas
- **Teoria Regulatória:** Teorias sobre regulação e intervenção

### PASSO 4: DOMÍNIO METODOLÓGICO
Explore aspectos metodológicos:

**Métodos Econométricos:**
- **Métodos Disponíveis:** Quais métodos econométricos você domina?
- **Métodos Requeridos:** Quais métodos são necessários para este projeto?
- **Limitações Metodológicas:** Quais são as limitações dos métodos?
- **Inovações Metodológicas:** Há oportunidades de inovação metodológica?

**Requisitos Técnicos:**

- **Dados:** Quais são os requisitos de dados e qualidade?
- **Computação:** Há requisitos computacionais específicos?
- **Expertise:** Que nível de expertise técnica está disponível?

**Abordagens de Validação:**
- **Validação Interna:** Como validar internamente os resultados?
- **Validação Externa:** Como comparar com estudos existentes?
- **Validação Cruzada:** Quais métodos de validação cruzada usar?
- **Sensibilidade:** Como testar sensibilidade dos resultados?

- **Desafios Específicos:** Particularidades do mercado brasileiro

### PASSO 6: TÉCNICAS DE ELICITAÇÃO
Selecione as técnicas de elicitação apropriadas:

**Técnicas Individuais:**
- [ ] **Entrevista Estruturada:** Perguntas pré-definidas com roteiro
- [ ] **Entrevista Semi-estruturada:** Perguntas guia com flexibilidade
- [ ] **Questionário:** Perguntas padronizadas para resposta escrita

**Técnicas de Grupo:**

- [ ] **Método Nominal de Grupo:** Geração individual + discussão em grupo
- [ ] **Técnica de Phillips 66:** Discussão em subgrupos

**Técnicas Especializadas:**
- [ ] **Elicititação de Conhecimento Especialista:** Extração de conhecimento de especialistas
- [ ] **Análise Hierárquica:** Priorização através de comparações pareadas

- [ ] **Análise de Decisão:** Estruturação de problemas de decisão
- [ ] **Simulação:** Modelagem e simulação de cenários

## FRAMEWORK DE ELICITAÇÃO ESTRUTURADA

### Fase 1: Preparação
1. **Definição do Escopo:** Clarificar objetivos e limites
2. **Identificação de Stakeholders:** Mapear todos os interessados
3. **Seleção de Técnicas:** Escolher métodos apropriados
4. **Preparação de Materiais:** Desenvolver guias e instrumentos
5. **Agendamento:** Coordenar horários e logística

### Fase 2: Execução
1. **Abertura:** Estabelecer contexto e expectativas
2. **Elicitação Principal:** Aplicar técnicas selecionadas
3. **Clarificação:** Responder dúvidas e refinar conceitos
4. **Consolidação:** Organizar e estruturar informações
5. **Validação:** Verificar compreensão e consenso

### Fase 3: Análise
1. **Organização:** Estruturar informações coletadas
2. **Análise de Conteúdo:** Identificar padrões e temas
3. **Triangulação:** Comparar diferentes fontes de informação
4. **Validação Cruzada:** Verificar consistência interna
5. **Síntese:** Integrar resultados em conclusões

### Fase 4: Documentação
1. **Registro Detalhado:** Documentar todo o processo
2. **Análise de Viés:** Identificar e documentar vieses potenciais
3. **Limitações:** Documentar limitações do processo
4. **Recomendações:** Fornecer recomendações baseadas nos resultados
5. **Plano de Ação:** Desenvolver plano de implementação
