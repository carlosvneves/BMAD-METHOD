# Automated Data Science Report Generation Task

This task provides comprehensive automated report generation capabilities for data science projects, including real-time dashboards, performance monitoring, and automated review features.

## Process

### 1. Report Configuration & Setup

[[LLM: Begin by understanding the reporting requirements, data sources, and automation needs. Configure the automated reporting system based on project specifications.]]

1. **Report Requirements Analysis**
   - Identify key stakeholders and their information needs
   - Determine report frequency and distribution requirements
   - Define KPIs and metrics to be tracked
   - Establish data sources and integration points
   - Configure automated triggers and schedules

2. **Report Type Selection**
   - Real-time monitoring dashboards
   - Daily/weekly/monthly summary reports
   - Performance tracking reports
   - Anomaly detection alerts
   - Predictive insights reports

### 2. Automated Report Generation Workflow

#### Data Collection & Processing

[[LLM: Design automated data collection and processing pipeline for report generation.]]

1. **Automated Data Ingestion**
   - Configure data source connections
   - Set up automated data refresh schedules
   - Implement data quality checks and validation
   - Handle missing data and anomalies
   - Maintain data lineage and versioning

2. **Automated Data Processing**
   - Apply data transformations and cleaning
   - Calculate derived metrics and KPIs
   - Perform statistical analysis and aggregations
   - Generate time-based comparisons and trends
   - Handle seasonal adjustments and normalizations

#### Report Generation Engine

[[LLM: Design the core report generation engine with templating and automation capabilities.]]

1. **Template-Based Report Generation**
   - Use predefined templates for consistency
   - Dynamically populate data and metrics
   - Generate visualizations and charts
   - Format for different output formats (PDF, HTML, email)
   - Include executive summaries and key insights

2. **Automated Insights Generation**
   - Apply natural language generation for insights
   - Identify significant trends and anomalies
   - Generate recommendations based on findings
   - Include confidence intervals and statistical significance
   - Provide contextual explanations and interpretations

3. **Automated Review & Validation**
   - Run automated quality checks on reports
   - Validate statistical calculations and methodologies
   - Check for data consistency and completeness
   - Flag potential issues or areas needing attention
   - Generate validation reports and audit trails

### 3. Automated Reporting Features

#### Real-Time Dashboards

[[LLM: Design interactive real-time dashboards with automated updates and alerting.]]

1. **Dashboard Configuration**
   - Create role-based dashboard views
   - Set up real-time data refresh intervals
   - Configure interactive filtering and drill-downs
   - Implement responsive design for multiple devices
   - Include performance optimization for large datasets

2. **Automated Alerting System**
   - Configure threshold-based alerts
   - Set up anomaly detection notifications
   - Implement multi-channel alert delivery (email, Slack, SMS)
   - Include escalation procedures and SLA monitoring
   - Provide alert suppression and maintenance windows

#### Scheduled Reporting

[[LLM: Implement scheduled reporting with automated distribution and archival.]]

1. **Report Scheduling Engine**
   - Configure cron-based scheduling
   - Handle timezone conversions and business calendars
   - Implement dependency management between reports
   - Support on-demand and ad-hoc report generation
   - Maintain report generation history and logs

2. **Automated Distribution**
   - Configure email distribution lists
   - Set up file system and cloud storage outputs
   - Integrate with collaboration platforms (Teams, Slack)
   - Implement access control and security measures
   - Handle failed deliveries and retry logic

   - Provide improvement recommendations

4. **Content Review Automation**
   - Automated grammar and spelling checks

   - Clarity and readability assessments
   - Executive summary quality evaluation
